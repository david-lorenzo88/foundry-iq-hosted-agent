MCP or REST? We chose REST

knowledge_base.py:1–9

A Foundry IQ knowledge base can be queried through its MCP endpoint or through REST /retrieve.

MCP is less wiring. But only REST returns the activity array: the query plan, the subqueries and their timings. That’s what the trace panel draws.

"""Foundry IQ knowledge base access for the hosted agent.The agent queries the knowledge base through its REST ``/retrieve`` endpoint ratherthan its MCP endpoint. Both are supported ways to query a Foundry IQ knowledge base,but only ``/retrieve`` returns the ``activity`` array describing how the answer wasassembled: which model planned the query, how it decomposed the question intosubqueries, and how long each one took.

Likely questions

Why not MCP?
Less code, but no visibility into how retrieval worked.
What does it cost?
The model call plus 40k–250k agentic reasoning tokens per question in the knowledge base.
Must it be Agent Framework?
No. Hosted agents run any Python or C# code; this one happens to use Agent Framework.
